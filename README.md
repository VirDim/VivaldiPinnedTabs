# Vivaldi Fixed Pinned Vertical Tabs

Небольшой UI-мод для Vivaldi с вертикальной панелью вкладок.

Мод оставляет закреплённые вкладки и разделитель на месте, а обычные вкладки прокручиваются отдельно под ними. Также используется собственный автоскрывающийся scrollbar, который отображается только в области обычных вкладок и не ломает изменение ширины панели или меню Workspace.

Проверено на:

- Vivaldi 8.2.4133.68
- Official Build
- 64-bit
- Windows

## Возможности

- закреплённые вкладки всегда остаются сверху;
- обычные вкладки прокручиваются под закреплёнными;
- разделитель между pinned и обычными вкладками остаётся на месте;
- scrollbar отображается только для обычных вкладок;
- scrollbar появляется при прокрутке и автоматически скрывается;
- scrollbar не занимает место в layout;
- сохраняется штатное изменение ширины вертикальной панели вкладок;
- меню выбора Workspace не перекрывается закреплёнными вкладками;
- длинные названия pinned-вкладок не растягивают панель;
- количество закреплённых вкладок можно менять без ручного редактирования CSS.

## Файлы

```text
.
├── pinned-tabs.css
├── pinned-tabs.js
└── README.md
```

`pinned-tabs.css` отвечает за закрепление pinned-вкладок и разделителя, а также скрывает штатный scrollbar визуально, не меняя его геометрию.

`pinned-tabs.js` рисует собственный автоскрывающийся scrollbar внутри панели вкладок и следит за изменениями интерфейса Vivaldi.

## Установка CSS

### 1. Включите CSS-модификации

Откройте:

```text
vivaldi://experiments
```

Включите:

```text
Allow for using CSS modifications
```

### 2. Укажите папку с CSS

Откройте:

```text
Настройки → Внешний вид → Custom UI Modifications
```

Выберите папку, в которой находится:

```text
pinned-tabs.css
```

Если у вас уже были другие версии этого мода, удалите или отключите старые CSS-файлы, чтобы правила не конфликтовали.

## Установка JavaScript

> Важно: подключение JavaScript к UI Vivaldi является неофициальной модификацией. После обновления браузера её обычно требуется подключить заново.

### 1. Найдите каталог установленной версии Vivaldi

Откройте:

```text
vivaldi://about
```

Посмотрите значение:

```text
Executable Path
```

Для Windows каталог обычно выглядит примерно так:

```text
C:\Users\<USER>\AppData\Local\Vivaldi\Application\8.2.4133.68\resources\vivaldi\
```

В этой папке должен находиться файл:

```text
window.html
```

### 2. Сделайте резервную копию

Перед изменением `window.html` рекомендуется создать его копию, например:

```text
window.html.bak
```

### 3. Скопируйте JavaScript

Поместите файл:

```text
pinned-tabs.js
```

рядом с:

```text
window.html
```

### 4. Подключите скрипт

Откройте `window.html` в текстовом редакторе и перед:

```html
</body>
```

добавьте:

```html
<script src="pinned-tabs.js"></script>
```

В результате конец файла должен выглядеть примерно так:

```html
<body>
    ...
    <script src="pinned-tabs.js"></script>
</body>
```

### 5. Перезапустите Vivaldi

Полностью закройте Vivaldi, включая фоновые процессы, и запустите браузер снова.

## Как это работает

Vivaldi сам рассчитывает координаты и размеры вкладок через внутренние CSS-переменные, включая:

```text
--PositionX
--PositionY
--Width
--Height
```

Мод использует эти значения вместо ручного задания размеров.

Закреплённые вкладки переводятся в `position: sticky`, но их штатная ширина и высота сохраняются.

Разделитель между pinned и обычными вкладками также становится sticky.

Штатный scrollbar Vivaldi остаётся частью настоящего scroll-контейнера и продолжает участвовать во внутренних расчётах браузера, но визуально становится прозрачным.

`pinned-tabs.js` поверх него рисует собственный scrollbar, который:

- начинается ниже pinned-вкладок и разделителя;
- отображает положение списка обычных вкладок;
- появляется при прокрутке;
- скрывается примерно через 750 мс;
- не принимает события мыши (`pointer-events: none`);
- не мешает штатному resize вертикальной панели.

## Обновления Vivaldi

После обновления Vivaldi каталог версии обычно меняется, например:

```text
8.2.4133.68
```

может смениться на:

```text
8.3.x.x
```

В этом случае потребуется:

1. найти новый каталог `resources\vivaldi`;
2. снова скопировать туда `pinned-tabs.js`;
3. снова добавить подключение скрипта в новый `window.html`.

CSS-модификация обычно продолжает работать из указанной пользователем папки.

## Совместимость

Мод разрабатывался и проверялся на:

```text
Vivaldi 8.2.4133.68 (Official Build) (64-bit)
```

с вертикальным расположением вкладок.

На других версиях Vivaldi внутренние классы и DOM-структура интерфейса могут отличаться, поэтому совместимость не гарантируется.

## Отключение

Чтобы временно отключить мод:

1. уберите или переименуйте `pinned-tabs.css`;
2. удалите из `window.html` строку:

```html
<script src="pinned-tabs.js"></script>
```

3. полностью перезапустите Vivaldi.

Для полного возврата исходного состояния можно восстановить сохранённую копию `window.html`.

## Примечание

Это неофициальная модификация пользовательского интерфейса Vivaldi и не является частью самого браузера.
